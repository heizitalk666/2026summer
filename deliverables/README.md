### 丙的复现链缺口

`丙-异常/README.md` 的复现步骤引用了三个脚本，**仓库里（main 与旧分支都）不存在**：

- `training/augment_verify_geometry.py`
- `training/bench_anomaly.py`
- `training/export_padim_onnx.py`

`patrol/perception/anomaly.py` 里也只有 `StatisticalAnomaly` 与
`EfficientADAnomaly`，**没有 PaDiM 实现**；`configs/system.yaml` 的
`perception.l3.model` 仍是 `efficientad_s`，不是那份 README 说的 `padim_s`。
所以「漏报 90.8 % → 3.3 %」这张表目前谁都跑不出来。这些是纯文本文件，
不存在"太大传不上来"的问题——**请丙补交**。

每个目录里除了 `README.md`（一页纸，进 PPT）之外，还有一份
`避坑清单.md` / `补齐清单.md`——**那是工作用的，不进 PPT**。
里面是组长核对代码时记下的坑，每条都指到了行号，开工前先扫一遍。

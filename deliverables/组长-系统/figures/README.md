| 文件名 | 内容 | 进 PPT 哪一页 | 出自 |
|---|---|---|---|
| `zoom_compare.png` | 同一块压力表 z=1 与 z=3 的车载视角对比 | **立论页（核心）** | `viewer --demo-zoom` |
| `thirdperson_compare.png` | 同一件事的第三人称：视锥从 60° 收到 21.8° 并套住那块表 | 立论页 | `viewer --demo-thirdperson` |

| `repeatability_seeds.png` | 重复性在 N 次独立标定上的分布与限值线 | **精度页（要害）** | `make_figures.py` |

## 三张图各自回答一个问题

**`zoom_compare` 与 `thirdperson_compare` 是一对**，必须放一起：前者说"表盘从
50 px 放大到 150 px"，后者说"视场从 60° 收到 21.8° 并且正好套住那块表"。
一个从车的眼睛里看，一个从旁边看着车。放一起，「停车 → 对准 → 变焦 → 再看一眼」
这句话不需要再解释。**单独放任何一张，说服力都要打折。**

**`step_response` 的第三条线才是重点。** 前两条（z=1 超调 4.1 %、z=3 超调 1.0 %）
只说明参数整好了；第三条是关掉增益调度之后的 z=3，超调 42.7 %。同样的 PID 参数、
同样的对象，只是不按变焦倍率折算控制量，超调就差 40 个百分点——**这是方案书
§6.3.2 那段推导唯一的实测证据**。

**`repeatability_seeds` 是唯一一张"指标没达标"的图，别把它藏起来。**
重复性限值 0.3 % FS，多次独立标定的中位落在限值之上。把分布画出来比写一个数
更有说服力：它证明这不是某一次运气差，是系统性地压在线上。

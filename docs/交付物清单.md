# 交付物清单

**给组员看的：你要交什么。给组长看的：你该收到什么、怎么验收。**

## 总原则

交代码、交权重、交"我训完了"——**都不算交付**。组长拿到之后要能**直接粘进 PPT**，
所以每个人交的是同样三样东西：

1. **一张图**（PNG，能单独看懂，坐标轴有标注）
2. **一张数字表**（Markdown 表格，直接复制）
3. **一句话结论**（这张图/这张表证明了什么，一句话说完）

再加上产物本身（权重、npz、json），供复现。

**交不出来的，如实写"未做/未验证"，不要交一个凑出来的数。**
这个项目的习惯是 README 里挂着"重复性压线超差"——保持住。

---

## 目录约定

每人在仓库根目录建自己的文件夹，**只交这一个文件夹**：

```
deliverables/
├── 甲-检测/
│   ├── README.md          ← 一页纸，模板见下
│   ├── figures/           ← 进 PPT 的图
│   └── artifacts/         ← 权重、json，供复现
├── 乙-分割/
└── 丙-异常/
```

`deliverables/` 已在 `.gitignore` 之外，会进版本库；**权重文件太大就别提交**，
放网盘给个链接，`artifacts/` 里留一个 `where.txt` 写清楚在哪。

## 乙 · L2 分割

### 交什么

| 文件 | 从哪来 | 进 PPT 哪一页 |
|---|---|---|
| `figures/mask_check.png` | `gen_synthetic --preview` 的核对图 | 数据质量页 |
| `figures/iou_compare.png` | 自己画：numpy 基线 vs U-Net | 方案比选页 |
| `figures/reading_error.png` | 自己画：几何法 vs 学习法，按像素密度分档 | **读数精度页（核心）** |
| `artifacts/pixel.npz` | `train_segmenter` 产出（内含 `val_iou`） | 附录 |

### 关键数字表（必须有）

| 方法 | 针的 IoU | 读数误差 %FS | 单次耗时 | 结论 |
|---|---|---|---|---|
| 几何法（现默认） | — | 0.05 | 2.4 ms | 基线 |
| numpy 逻辑回归 | 0.182 | 0.11 | 5.5 ms | 已有 |
| U-Net（你训的） | | | | |

跑这条出对比数据：

```bash
python -m patrol.tools.bench_models --only reading --seg-weights <你的权重>
```

不给 `--seg-weights` 就只跑几何法那一列，所以**一定要传**。

### 结论怎么写

**你的任务不是证明学习法更好，是给出一个诚实的比选结论。**
赢不了几何法，那"在本项目的表计上几何法更优"本身就是成果——任务书写的是
"要求学生调研并比选后确定方案"，比选出的结论是"不用"也完全合格。

如果赢了，重点报告**在哪类样本上赢的**（方形表？反光？指针与背景同色？）。

### RKNN 导出记录（任务书第 2 项，别漏）

```bash
python -m training.export_rknn ...
```

`artifacts/rknn_export.md` 至少写清楚四件事：

1. 导出成功没有（ONNX → RKNN 这一步）
2. ONNX 冒烟推理的输出对不对
3. **INT8 掉点多少**（FP32 vs INT8 的指标差）
4. 量化校准集用的是什么——**必须是 `evidence/` 里的本场景图，不许用 COCO**

没有板子，**"上板测速"这一项如实写"未验证，缺硬件"**，不要编一个数。

## 组长怎么验收

对每一份交付，问四个问题：

1. **这张图我能不能不加解释就放进 PPT？** 坐标轴有没有标注、图例看不看得懂
2. **这个数字是怎么来的？** 复现命令跑一遍，跑不出来就打回去
3. **它对应任务书的哪一项？** 对不上的说明做偏了
4. **"未做"那一栏是不是空的？** 空的大概率是没敢写，要追问

### 对应到任务书

| 任务书研究内容 | 谁交 | 交付物 |
|---|---|---|
| 第 3 项 目标检测、已知缺陷识别 | 甲 | mAP 表 + 混淆矩阵 + 切换前后对比表 |
| 第 3 项 图像质量评价 | 已完成 | `quality.py` 四项指标，组长直接引用 |
| 第 3 项 未知异常检测 | 丙 | 统计法 vs EfficientAD 对比表 |
| 第 2 项 模型部署 | 丙 | RKNN 导出记录（含 INT8 掉点） |
| 第 8 项 识别效果 | 甲 + 乙 | mAP 表 + 读数误差分档表 |
| 第 4/5/6 项 跟踪、状态机、证据包 | 已完成 | 组长从 `docs/演示指南.md` 取现成材料 |
| 第 1/7/8 项 集成、云端、稳定性 | 已完成 | 同上 |

**注意最后两行**：任务书八项里有五项已经完成，组长做 PPT 时直接从
`docs/演示指南.md` 和现有实测数据里取，不用等任何人。

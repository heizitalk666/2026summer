## 一、新增的两节

这两条是 B 类差异：任务书要求、ICD 里有、**方案书里 0 次出现**。

### B1 → 新增 6.2.3　未知异常检测

方案书全文没有提到过异常检测，而任务书第 3 项点名要「未知异常检测」，并列了
EfficientAD / PaDiM。新增一节说清三件事：

1. 为什么需要它——渗漏油、呼吸器变色这类问题**没有公开标注数据**，室内场景更没有，
   监督学习这条路在数据上就走不通（方案书 2.4.5 自己列了这条约束）
2. 非监督怎么绕开它——只用正常样本训练，而正常样本"巡检跑一轮就攒下一批"
3. 统计法与学习法两条通路要在**同一批样本**上比选，比选结论是"不启用学习法"也是成果

这一节同时承接了 A2 让出的通路：渗漏油不再作为监督类别去训，改由 L3 当"未知异常"兜住。

### B2 → 新增 6.3.7　复核预算与失锁抑制

方案书全文没有"复核预算"，也没有"定位失锁"。而这两样都是 ICD §7.3 / §7.4 的核心机制。
新增一节写清：

- $N_{\max} = \lfloor (T_{\max} - L/v) / T_r \rfloor$，按决议后的 $T_r = 9.2$ s 得 **21 次**
- 不设预算的后果不是慢，是**巡检跑不完**——车停在半路反复复核，路线尽头一次也没看过
- 预算耗尽后事件进顺延队列，新颖度取 0.3 而不是 0（取 0 会让复现的缺陷永远排不上队）
- 三条抑制规则各挡一类死循环，少一条补不上
- 定位失锁时一律不进复核，且**按抑制处理不按故障处理**——车照常巡航，只是不做主动测量

## 三、没有改的地方

- **C5（视场角 θ）没有动方案书。** §3.4 选型表写 60°–20°，§4.1.3 由它自己给的
  $f = 4$ mm / $w = 5.37$ mm 算出来是 67°–25°，两处对不上，而 §5.3 全部按 60° 代入。
  决议是**暂按 60° 冻结**，改动最小；代价与风险敞口写进了 ICD §3.2 的新增条款
  （实测偏差 >3° 须重算 $d_{\max}$ 与路线标定规范并通报全组）。**方案书内部这处
  不自洽保持原样**，它是 C5 那条决议的原始证据，改掉就看不出为什么要加那条条款。
- **10.2 人员分工表（A/B/C/D 四角色）没有动。** 它与 `docs/后续计划与分工.md` 的
  甲/乙/丙/组长分工不是一回事：方案书写的是**环节归属**，分工书写的是**这三周谁做什么**。
  两份都对，各自管各自的范围。
- **第九章的测试方法与指标没有动。** 决议没有涉及。

## 四、怎么复核这次修订

```bash
pip install python-docx
python3 docs/apply_docx_revisions.py --check      # 应当报「已改 0 处」
```

报 0 处说明文档里的每一条都已经是改后的状态。想看某条具体改了什么，
直接读 `docs/apply_docx_revisions.py` 里对应决议编号的那一项——原文与改后并排放着。
